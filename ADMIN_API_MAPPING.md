## 2. Security & Data Synchronization Guarantees

1. **Zero Unverified Payment Overrides:** `AdminController.reconcilePayment` never permits manual marking of unverified transactions as paid without checking the trusted Razorpay gateway (`razorpayInstance.orders.fetchPayments`) or verifying an HMAC-SHA256 signature.
2. **Sensitive Field Sanitization:** `AdminController.sanitizeUser` strips `passwordHash`, `resetPasswordToken`, and `resetPasswordExpires` before returning any user or instructor profile.
3. **Private Meeting Link Protection:** Live classroom meeting URLs (`liveSessionUrl`) and passcodes configured in `AdminSessions.tsx` are gated by `LearnerController.getLiveClasses` so unpaid users only see schedule previews.
4. **Immutable Audit Logging:** Every administrative mutation invokes `AdminController.logAudit`, recording actor ID, email, role, action, target entity, summary, and IP address in `AuditLog`.
